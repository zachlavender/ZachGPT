# ZachGPT - LLM from Scratch

## Purpose
Learning exercise to build an LLM from scratch. No TensorFlow or PyTorch - only NumPy and math packages to gain full understanding of fundamentals.

## Code Structure
```
notebooks/      # Jupyter notebook with all implementation
├── ZachGPT.ipynb   # Main notebook (tokenization → embeddings → attention → transformer → training)

data/           # Training data (raw and processed)
checkpoints/    # Model weights
```

## Package Management
Using pip with requirements.txt. Install with `pip install -r requirements.txt`.
